asr-agent — Arabic → German live transcription

A browser mic client streams speech over LiveKit to a GPU bot on Google Colab. The bot cuts the audio into sentences with a a Silero-VAD thread per speaker and transcribes every utterance with Cohere Transcribe Arabic. The Arabic text is translated to German by Qwen3-4B-Instruct in fp16 (on Kaggle: TranslateGemma 12B in 8 bit via llama.cpp, alone on one T4) and spoken by Gradium Phonon on the CPU (German model CC BY-NC 4.0: not for commercial use without an agreement with Gradium). Every stage is an independent worker, so the transcript, the translation and the speech stream back in near real time.

🖥 Your PC

FastAPI server (backend/main.py) + web client (frontend/index.html). Sends the mic and a LiveKit token; renders the Cohere transcript.

☁ LiveKit Cloud

The transport. Carries the audio track to the bot and the per-backend transcript data messages, the translation, and the optional TTS audio back to the browser.

🤖 Colab T4 / Kaggle T4 ×2

bot.py: VAD threads + Cohere ASR + translator on the GPU + Phonon spoken output on the CPU, run as a streaming pipeline; TTS_BACKEND=xtts selects XTTS-v2 instead.

What the bot does with each sentence

Every stage is an independent worker with its own queue, so stage N of one utterance overlaps stage N+1 of the previous one. GPU access is admitted by a bounded, priority-aware scheduler, and the real-time playout runs in its own task so it can never stall a GPU stage. A short pause does not end a sentence unless the segment already holds MIN_SENTENCE_SECONDS of speech, so a mid-sentence breath is not mistaken for the end of a sentence.

Running it

You need two things: a LiveKit Cloud account (Project → API keys) and a Google Colab account (a free T4 GPU is enough; Kaggle's T4 ×2 notebook runs TranslateGemma 12B). Then:

  1. Start the bot in Colab. In colab_agent.ipynb set the runtime to Runtime > Change runtime type > T4 GPU, then Runtime > Run all. The first cell asks you to upload your .env file (copy .env.example, fill in the three LiveKit keys — more below). The install cell adds the extra packages automatically. First run downloads the models, so wait a few minutes until the log shows READY: Bot is in room ... — the bot is now listening in the room.
  2. Configure the .env with the LiveKit credentials (LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET) and a Hugging Face HF_TOKEN with access to the gated repositories:
    • Gated models: accept the terms for Cohere Transcribe Arabic and Phonon German (gradium/phonon-40m-de) on Hugging Face, then add an authorized HF_TOKEN to the .env. Qwen3 is public.
    • COHERE_4BIT=1 — optional; 4-bit-quantizes the Cohere ASR model to free VRAM for the fp16 translator.
    • TRANSLATION_MODEL — Qwen/Qwen3-4B-Instruct-2507 by default; an 8B variant translates better but decodes slower.
    • Spoken German output needs no configuration — Phonon uses the German model's default voice, so just enable "German speech output" in the web app. Set PHONON_VOICE for another catalog voice, or TTS_BACKEND=xtts for XTTS-v2 (XTTS_SPEAKER / XTTS_SPEAKER_WAV).
    • Other overrides: LIVEKIT_ROOM, COHERE_MODEL, TRANSLATION_SOURCE_LANG / TRANSLATION_TARGET_LANG (default ar / de), MIN_SENTENCE_SECONDS, MAX_UTTERANCE_SECONDS (default 12 s, longer utterances are split).
  3. VRAM budget: Cohere ASR (3.85 GiB) and the fp16 Qwen3 translator (7.49 GiB) use about 11.3 GiB of a T4's 15 GiB, before inference memory; Phonon runs on the CPU and needs no GPU memory. Startup loads ASR, then the TTS, then the translator, and requires successful warm-ups. The last cell saves output to /content/bot.log; installation output is in /content/install.log.
  4. Start the web app on your PC. Install pip install -r requirements.txt, put the same LiveKit credentials in a local .env and run python -m uvicorn backend.main:app --port 8000 from the repo root.
  5. Translate. Open http://127.0.0.1:8000, optionally enable the German speech output, click Start microphone and speak Arabic. The Arabic transcript appears on the left, the German translation on the right. All settings persist in localStorage; stop the Colab runtime (Runtime > Disconnect & delete) when you are done.

Troubleshooting: no READY line after ~5 minutes → check the Colab logs (most often a wrong token or a used-up free GPU quota); the web app shows “ASR bot missing” → the bot is not in the room yet; a model fails to load → accept both repository terms on huggingface.co and set HF_TOKEN.
