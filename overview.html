asr-agent — Arabic → German live transcription

A browser mic client streams speech over LiveKit to a GPU bot on Google Colab. The bot cuts the audio into sentences with a shared Silero-VAD segmenter and transcribes every utterance with Cohere Transcribe Arabic. The Arabic text is then translated to German by TranslateGemma (12B by default, or a smaller/faster 4B via GEMMA_TRANSLATION_MODEL), and the transcripts (plus optional German speech) are sent back to the browser in near real time.

🖥 Your PC

FastAPI server (backend/main.py) + web client (frontend/index.html). Sends the mic and a LiveKit token; renders the Cohere transcript.

☁ LiveKit Cloud

The transport. Carries the audio track to the bot and the per-backend transcript data messages, the translation, and the optional TTS audio back to the browser.

🤖 Colab (T4 GPU)

bot.py: shared Silero VAD + Cohere ASR + 4-bit TranslateGemma + optional F5-TTS spoken output (German fine-tune aihpi/F5-TTS-German); TTS_BACKEND=xtts selects XTTS-v2 instead.

What the bot does with each sentence

The Silero-VAD segmentation runs once per speaker and feeds Cohere. All GPU work (transcription, translation, TTS) is serialized through one shared lock, and finished utterances are always processed before live interim updates.

Running it

You need two things: a LiveKit Cloud account (Project → API keys) and a Google Colab account (a free T4 GPU is enough). Then:

  1. Start the bot in Colab. In colab_agent.ipynb set the runtime to Runtime > Change runtime type > T4 GPU, then Runtime > Run all. The first cell asks you to upload your .env file (copy .env.example, fill in the three LiveKit keys — more below). The install cell adds the extra packages automatically. First run downloads the models, so wait a few minutes until the log shows READY: Bot is in room ... — the bot is now listening in the room.
  2. Configure the .env with the LiveKit credentials (LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET) and a Hugging Face HF_TOKEN with access to the gated Cohere and TranslateGemma repositories:
    • Gated models: accept the terms for Cohere Transcribe Arabic and TranslateGemma on Hugging Face, then add an authorized HF_TOKEN to the .env.
    • COHERE_4BIT=1 — optional; 4-bit-quantizes the Cohere ASR model to save VRAM.
    • GEMMA_TRANSLATION_MODEL — google/translategemma-12b-it (default, best quality) or google/translategemma-4b-it for a smaller/faster model that uses less VRAM.
    • Spoken German output needs a reference voice — the default F5-TTS engine is a voice-cloning model, so set F5_REF_WAV (a ~5–10 s wav of the voice you want; a URL or a Colab file path) and F5_REF_TEXT (the exact text spoken in that clip) in the .env before enabling "German speech output" in the web app. Set TTS_BACKEND=xtts to use XTTS-v2 instead (no reference clip needed — it picks a pre-made voice via XTTS_SPEAKER / XTTS_SPEAKER_WAV).
    • Other overrides: LIVEKIT_ROOM, COHERE_MODEL, GEMMA_TRANSLATION_MODEL, TRANSLATION_SOURCE_LANG / TRANSLATION_TARGET_LANG (default ar / de), F5_GERMAN_REPO / F5_GERMAN_CKPT, MAX_UTTERANCE_SECONDS (default 20 s, longer utterances are split).
  3. VRAM budget on a T4 (15.75 GB): Cohere ASR plus 4-bit TranslateGemma (12B or 4B) fits without TTS — pick the 4B model if you need extra headroom. Enable COHERE_4BIT=1 to free more memory. The TTS model is not loaded at startup — it loads on the first spoken request (triggering a one-time ~2.7 GB checkpoint download), and the German F5-TTS model uses ~4.1 GB on GPU (fp16), so leave that much headroom before turning on the speech output; TTS_BACKEND=xtts uses the much smaller XTTS-v2 instead.
  4. Start the web app on your PC. Install pip install -r requirements.txt, put the same LiveKit credentials in a local .env and run python -m uvicorn backend.main:app --port 8000 from the repo root.
  5. Translate. Open http://127.0.0.1:8000, optionally enable the German speech output, click Start microphone and speak Arabic. The Arabic transcript appears on the left, the German translation on the right. All settings persist in localStorage; stop the Colab runtime (Runtime > Disconnect & delete) when you are done.

Troubleshooting: no READY line after ~5 minutes → check the Colab logs (most often a wrong token or a used-up free GPU quota); the web app shows “ASR bot missing” → the bot is not in the room yet; Cohere or TranslateGemma fails to load → accept both repository terms on huggingface.co and set HF_TOKEN.
