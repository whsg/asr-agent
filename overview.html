asr-agent — Arabic → German live transcription

A browser mic client streams speech over LiveKit to a GPU bot on Google Colab. The bot cuts the audio into sentences with a shared Silero-VAD segmenter and transcribes every utterance with one or two selectable ASR backends — Qwen3-ASR-1.7B and Cohere Transcribe Arabic (chosen via the ASR_BACKENDS env var). The text of the backend you pick in the web app is translated to German by a selectable translation model — TranslateGemma-12B (default) or Qwen3-8B (chosen via TRANSLATION_BACKEND, only one loaded) — and the transcripts (plus optional German speech) are sent back to the browser in near real time.

🖥 Your PC

FastAPI server (backend/main.py) + web client (frontend/index.html). Sends the mic and a LiveKit token; renders the transcript in three display modes (Qwen, Cohere, or both side by side) and remembers the settings in localStorage.

☁ LiveKit Cloud

The transport. Carries the audio track to the bot and the per-backend transcript data messages, the translation, and the optional TTS audio back to the browser.

🤖 Colab (T4 GPU)

bot.py: shared Silero VAD + selectable ASR backends (ASR_BACKENDS: qwen, cohere, or qwen,cohere) + a selectable 4-bit translator (TRANSLATION_BACKEND: translategemma 12B (default) or qwen3 8B — only one loaded) + XTTS-v2 (optional TTS). One async worker per enabled backend, all GPU work behind a single shared lock.

What the bot does with each sentence

The Silero-VAD segmentation runs once per speaker and feeds every enabled backend. Each backend has its own async transcription worker and its own LiveKit topic; all GPU work (transcription, translation, TTS) is serialized through one shared lock, and finished utterances are always processed before live interim updates.

Running it

You need two things: a LiveKit Cloud account (Project → API keys) and a Google Colab account (a free T4 GPU is enough). Then:

  1. Start the bot in Colab. In colab_agent.ipynb set the runtime to Runtime > Change runtime type > T4 GPU, then Runtime > Run all. The first cell asks you to upload your .env file (copy .env.example, fill in the three LiveKit keys — more below). The install cell adds the extra packages automatically. First run downloads the models, so wait a few minutes until the log shows READY: Bot is in room ... — the bot is now listening in the room.
  2. Configure the .env with the LiveKit credentials (LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET) and, to pick your ASR engine(s) and translator, set ASR_BACKENDS and TRANSLATION_BACKEND:
    • ASR_BACKENDS — qwen (default, Qwen3-ASR-1.7B), cohere (CohereLabs/cohere-transcribe-arabic-07-2026, a 2B Conformer), or qwen,cohere for both side by side.
    • TRANSLATION_BACKEND — the German translator (only one is loaded): translategemma (default, google/translategemma-12b-it) or qwen3 (Qwen/Qwen3-8B); both run at 4-bit. The Qwen3 one keeps up to 3 previous lines as context; TranslateGemma does not.
    • Gated repos need HF_TOKEN: the default translategemma translator and the cohere ASR backend are gated on huggingface.co — accept their license terms and add a HF_TOKEN to the .env; both also need transformers>=5.4.0 (Colab preinstalls it).
    • COHERE_4BIT=1 — optional; 4-bit-quantizes the Cohere ASR model to save VRAM.
    • Optional overrides: QWEN_MODEL, QWEN_LANGUAGE, LIVEKIT_ROOM, GEMMA_TRANSLATION_MODEL, QWEN_TRANSLATION_MODEL, TRANSLATION_SOURCE_LANG / TRANSLATION_TARGET_LANG (default ar / de), XTTS_SPEAKER / XTTS_SPEAKER_WAV, MAX_UTTERANCE_SECONDS (default 12 s, longer utterances are split).
  3. VRAM budget on a T4 (15.75 GB): the default stack — Qwen3-ASR-1.7B (bf16, ~3.5 GB) + TranslateGemma-12B (4-bit, ~7 GB) — is ≈ 11 GB, so one ASR backend plus the default translator fits with room to spare. Running both ASR backends next to the 12B translator (≈ 14.5 GB) is tight: enable COHERE_4BIT=1, or pick the lighter qwen3 8B translator (4-bit, ~5 GB) via TRANSLATION_BACKEND=qwen3.
  4. Start the web app on your PC. Install pip install -r requirements.txt, put the same LiveKit credentials in a local .env and run python -m uvicorn backend.main:app --port 8000 from the repo root.
  5. Translate. Open http://127.0.0.1:8000, pick the display mode (Qwen3-ASR / Cohere Transcribe Arabic / both side by side — when both run, choose whose text gets translated to German), optionally enable the German speech output, click Start microphone and speak Arabic. The Arabic transcript appears on the left, the German translation on the right. All settings persist in localStorage; stop the Colab runtime (Runtime > Disconnect & delete) when you are done.

Troubleshooting: no READY line after ~5 minutes → check the Colab logs (most often a wrong token or a used-up free GPU quota); the web app shows “ASR bot missing” → the bot is not in the room yet; the translator or the Cohere ASR model fails to load → both are gated, so accept the repo terms on huggingface.co and set HF_TOKEN (or use TRANSLATION_BACKEND=qwen3, which is not gated).
